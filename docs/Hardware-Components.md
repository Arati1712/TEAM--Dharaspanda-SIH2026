# Hardware Components

| Component | Purpose |
|---|---|
| ESP32 | Main controller for collecting and processing sensor data |
| MPU6050 | Measures acceleration and tilt/inclination |
| ADXL345 | Measures acceleration and ground movement |
| Capacitive Soil Moisture Sensor | Measures soil moisture conditions |
| LoRa Module | Provides long-range wireless communication |
| 433 MHz Antenna | Used with the LoRa communication module |
